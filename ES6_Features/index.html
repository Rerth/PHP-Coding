ES6 Features You Should Know

This page shows modern JavaScript writing style that is commonly used in React.

1. Let and Const

let count = 0;
const name = 'React';
count += 1;

2. Arrow Functions

const greet = (name) => `Hello, ${name}!`;
console.log(greet('Ada'));

3. Template Literals

const user = 'Sam';
const message = `Welcome ${user}`;

4. Destructuring

const userInfo = { name: 'Sara', age: 22 };
const { name, age } = userInfo;

5. Default Parameters

const welcome = (name = 'Guest') => `Hello ${name}`;

6. Spread and Rest Operators

const nums = [1, 2, 3];
const moreNums = [...nums, 4, 5];
const sum = (...values) => values.reduce((a, b) => a + b, 0);

7. Import and Export

export const title = 'ES6';
import { title } from './example.js';

8. Classes

class Person {
  constructor(name) {
    this.name = name;
  }

  greet() {
    return `Hi, ${this.name}`;
  }
}
