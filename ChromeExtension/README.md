# Quick Notes Chrome Extension

A simple Chrome extension that lets you save quick notes from the browser toolbar.

## Load it in Chrome
1. Open chrome://extensions/
2. Turn on Developer mode.
3. Click "Load unpacked".
4. Select the ChromeExtension folder.

## What it does
- Saves a note locally in your browser.
- Lets you clear the note anytime.
- Works as a popup from the extension toolbar.
